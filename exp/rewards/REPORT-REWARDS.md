# 전투 보상 3택 1 검증

사람 흉내(`guardFirst`)와 대응(`adaptive`) 봇을 시드 8192~12287에서 각 조건 4,096판씩 비교했습니다. 시드 0~511에서 무보상 사람 흉내 봇으로 특전 선택 가중치를 계산하고, 네 조건에 같은 시작 특전을 적용했습니다. 보상 정책은 약초 붕대가 나오면 붕대, 그 외에는 화면의 첫 유물을 고릅니다. 이 정책에서는 조율 잔편을 고르지 않습니다. 평균 턴의 분모는 해당 전투에 진입한 판으로, 승패를 모두 포함합니다. [재현 스크립트](study.mjs)

| 봇 | 보상 | 완주 / 4,096 | 졸개 평균 턴 | 정예 평균 턴 | 보스 평균 턴 |

3택 1 완주율은 기획서 추정인 사람 흉내 40~45%와 대응 62~66%에 들었습니다. 보스 평균은 두 봇 모두 7턴 이내였습니다. 적 체력·피해와 보상 수치는 기획서의 시험 시작값을 사용했습니다.

초기 편성에서는 두 번의 선택 동안 쇠쐐기보다 앞선 카드로 세 자리가 찼습니다. 쇠쐐기의 힘 모으기 적 제한과 발동은 시험에서 확인했습니다. 초기 헤드리스 캡처의 힘 모으기 적 예고에는 심장석 거인 아이콘과 힘 모으기 아이콘이 표시됩니다.

## 힘 모으기 적 앞 쇠쐐기 우선

다음 적이 힘을 모으고 쇠쐐기를 보유하지 않으면 빈자리를 쇠쐐기 → 저울추 → 받침 버클 → 되감기 핀 순서로 채웁니다. 이미 찬 카드는 유지합니다. 같은 시드와 선택 정책으로 각 봇을 4,096판씩 다시 돌렸습니다.

| 봇 | 완주율 초기 → 변경 | 보스 평균 턴 초기 → 변경 | 쇠쐐기 선택 |
| --- | ---: | ---: | ---: |
| 사람 흉내 | 43.36% → 43.41% (1,778 / 4,096) | 6.62 → 6.59 | 461회 |
| 대응 | 63.89% → 64.04% (2,623 / 4,096) | 6.53 → 6.46 | 1,452회 |

사람 흉내 완주율은 45% 이내이며 두 봇의 보스 평균은 7턴 이내입니다. 390×844 헤드리스에서 심장석 거인 전의 빈자리에 쇠쐐기가 뜨고 획득 후 보유 띠에 표시되는 것을 확인했습니다. 이전 편성에서 고른 카드가 목록에서 빠진 경우 해당 미리보기만 초기화하고 등반은 이어집니다.
