# 기믹 적 명단

등반 시드로 1전투 졸개 4종과 2전투 엘리트 3종에서 한 종씩 고른다. 적 선택은 특전 제시·주사위 굴림과 별도 채널을 쓴다. 3전투는 고정 보스다. 다음 전투에 현재 체력을 그대로 가져간다.

## 명단과 수의 순서

표의 피해는 턴 성장·해금·호위 보정 전 기본값이다. 엘리트는 해금당 고정 타격에 각각 +2, 보스는 +1을 받는다. 졸개는 경과 턴마다 타격당 +1, 체력 비례 엘리트의 고정 타격은 +2를 받으며, 두 경우 모두 턴 성장분은 타격당 최대 +6이다.

## 4차 클릭 검증 뒤 조정

- 적의 한 턴 공격 합은 성장·해금·격분·호위를 적용한 뒤 21로 제한한다. 연타는 각 타격에 비례해 21을 나눠 예고와 실제 피해에 쓴다. 방어를 뚫은 공격과 가시 반격을 합친 피해도 21까지다. 기본 최대 체력은 22이고 주사위 네 개의 최대 방어 합은 24다.
- 힘 모으기를 끊으면 상한 적용 후 치명 일격을 절반으로 내린다. 예를 들어 체력 비례 엘리트의 4턴 치명 일격은 해금 두 개일 때 기본 17 + 성장 6 + 해금 4를 21로 제한하고, 끊으면 10이다. 정확 방어와 룰렛은 이 최종 합을 쓴다.
- 호위 엘리트는 빼앗기 → 소환 → 힘 모으기 → 치명 일격 순이다. 빼앗은 주사위는 본체 누적 피해 10에서 회수하고, 남은 피해가 있어도 힘 모으기가 시작되면 돌려준다. 소환 턴에는 호위 아이콘 옆에 해당 턴의 공격 피해도 예고한다.
- 체력 비례 일격은 `max(4, ⌊현재 플레이어 체력 / 2⌋)`이다. 체력 24 → 피해 12, 체력 13 → 피해 6, 체력 4 → 피해 4다. 이 일격은 현재 체력만 사용하며 유료 재굴림 뒤 예고도 즉시 새로 계산한다.
- 보스 첫 봉인 공격은 기본 19 → 14로 내렸다. 해금 두 개를 더한 피해는 최대 16이다. 봉인된 5는 미배치 상태에서 5, 어느 칸에나 놓으면 0으로 표시된다. 재굴림은 가능하다.

## 기믹 규칙과 적용 수치

| 기믹 | 규칙 |
| --- | --- |
| 가시 | 해당 턴에 본체 공격 칸에 넣은 주사위마다 피해 6을 받는다. 방어로 상쇄되지 않으며 적을 처치할 때도 적용된다. 양쪽이 쓰러지면 패배다. |
| 자물쇠 | 다음 턴 첫 굴림에서 가장 낮은 주사위 하나를 잠근다. 동률이면 앞의 주사위를 고른다. 배치할 수 있고 재굴림은 막힌다. |
| 얼림 | 다음 턴 두 번째 기본 주사위를 1로 고정한다. 배치에는 1로 더하고 재굴림은 막힌다. |
| 격분 | 해당 턴에 재굴림을 쓰면 공격의 첫 타격에 +2를 더한다. 재굴림을 이어서 써도 한 번 적용한다. |
| 반응 | 본체 공격 칸의 주사위 합이 8 이상이면 한 방이 연타 2×2로 바뀐다. 바뀐 예고로 방어와 룰렛을 판정한다. |
| 체력 비례 일격 | 현재 체력의 절반을 내림하고 최소 4의 피해를 준다. |
| 봉인 5 | 보스 넉다운 직후 한 턴 적용한다. 각 칸에서 5를 0으로 계산하고 5를 포함한 족보도 막는다. |
| 주사위 빼앗기 | 세 번째 기본 주사위를 다음 턴에 뺀다. 본체에 준 공격·반격 피해가 10에 도달하거나 힘 모으기가 시작되면 되찾는다. |
| 호위 졸개 | 체력 5인 호위 한 마리를 부른다. 살아 있으면 본체 공격의 첫 타격에 +3을 더한다. 호위는 별도 공격 칸으로 때리며, 이번 배치로 호위를 처치하면 당장 +3이 사라진다. |

적 체력·공격 수치·턴별 배치는 아래 모의실험으로 조정했다. 잠긴 눈·얼린 1·봉인된 5는 각성 중에도 보존한다. 족보 해금은 본체 공격과 정확 방어에 적용한다.

## 기믹 턴의 배치
