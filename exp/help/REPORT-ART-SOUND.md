# 전투 그림과 소리 검증

탑의 문지기는 대기, 힘 모으기, 치명 일격 실행, 넉다운에 맞춰 자세를 바꿉니다. 가시 적에는 돌 파편 졸개를 연결했습니다. 공격 예고 중에는 준비 자세를, 실제로 공격하거나 피해를 입을 때는 해당 자세를 잠깐 보여 줍니다. 석실은 최신 99×176 원본이며, 그림과 석실을 정수 배율로 확대하고 발 기준점(문지기 24·46, 졸개 16·38)을 같은 바닥선에 맞췄습니다. 공격 예고와 체력 뒤에 어두운 판을 댔습니다.

첫 시작 특전을 직접 선택하면 석실 배경음과 굴림 소리가 시작됩니다. 이후 굴림, 놓기, 타격, 정확히 막기, 룰렛 틱과 정지, 해금, 승리, 패배에 효과음이 재생됩니다. 상단 스피커로 배경음과 효과음을 함께 끄거나 켤 수 있으며, 사전에 두 아이콘을 추가했습니다.

캐시가 비어 있는 Edge 모바일 환경에서 `npm run build` 뒤 Vite 미리보기의 시작 특전 선택 화면을 열고 측정했습니다. 첫 화면의 네트워크 요청은 HTML·JS·CSS 3개였습니다. 그림은 전투 진입 시 석실과 해당 적에 필요한 자세를 불러옵니다. 원본 WAV의 음질과 루프를 유지했고 소리를 활성화하는 첫 사용자 조작 이후에 받습니다.

## 390×844 확인

- 시드 91에서 방패 저금을 골라 전투 UI로 보스까지 등반했습니다. 대기, 힘 모으기, 치명 일격의 짧은 공격 자세, 넉다운 순서를 확인하고 최종 승리했습니다.
- 시드 3에서 가시 적의 준비, 피격, 공격, 반격 룰렛 중 대기 자세를 확인했습니다. 시드 16의 3배 픽셀 밀도에서는 큰 칼의 예상 충전을 띄운 상태로 헤더와 조작부가 화면 안에 들어오는지 확인했습니다. 캔버스 확대 배율과 발 위치도 검사했습니다.
- 사용자 조작 전에는 음원 요청과 재생이 없음을 확인했습니다. 소리를 끈 상태에서 주사위를 놓아도 효과음이 재생되지 않았고, 다시 켰을 때 배경음이 중복되지 않았습니다. 실제 재생 이벤트로 룰렛과 해금을 포함한 전투 효과음을 확인했고, 시드 12 패배까지 진행해 패배음을 확인했습니다.
