# 전투 그림과 소리 검증

## v5 · 390×844 캡처 측정

원화에서 각 인물의 자세를 다시 표본 추출해 프레임 안의 실루엣을 키웠습니다. 인물마다 가로·세로에 같은 표본 간격을 쓰고 자세 사이에도 그 간격을 유지했습니다. 원화의 표본 간격은 문지기 20픽셀, 졸개 26픽셀, 회귀자 22픽셀입니다. 390×844의 바닥선을 약 30 CSS 픽셀 위로 옮겼고, 예고판과 피해 숫자를 스프라이트 위에 두었습니다. 체력판은 발 아래에 있습니다.

프레임 크기는 투명 영역을 포함합니다. 불투명 경계 상자는 캡처에서 그림이 차지하는 최소 직사각형입니다. 문지기 대기 높이는 v4의 90에서 132 CSS 픽셀로, 회귀자 대기 높이는 81에서 108 CSS 픽셀로 커졌습니다. 졸개는 낮게 웅크린 자세를 유지합니다.

390×844 터치 환경의 Edge에서 프로덕션 빌드를 열었습니다. DPR 1·3에서 캔버스의 정수 좌표와 확대 배율, `imageSmoothingEnabled = false`, 발과 석실 바닥선 일치, 예고·체력판과 그림의 비겹침을 확인했습니다. 1배 픽셀 밀도에서 찍은 6장의 불투명 원본 픽셀 6,769개에 대해 같은 RGB의 3×3 블록 60,921픽셀을 대조했습니다. 실루엣 바로 바깥의 배경도 비교했고 색이 섞인 픽셀은 0개였습니다. [문지기와 회귀자 부분 4배 최근접 확대](v5-zoom.png)

## v5 · 압축 전후 용량

| 항목 | v4 WAV 빌드 | v5 MP3 빌드 |
| --- | ---: | ---: |
| 전투 그림 PNG 13개 | 8,366 B | 11,685 B |
| 음원 10개 | 6,423,164 B | 430,990 B |
| 그중 석실 배경음 | 5,292,044 B | 360,847 B |
| **그림·음원 합계** | **6,431,530 B** | **442,675 B** |

배경음은 96 kbps, 효과음은 80 kbps 스테레오 MP3로 인코딩했습니다. 그림·음원 합계가 93.1% 줄었습니다. 실제 UI에서 시드 91로 승리하고 시드 12에서 패배해 배경음, 굴림, 놓기, 타격, 정확히 막기, 룰렛 틱과 정지, 해금, 승리, 패배의 재생을 확인했습니다. 첫 사용자 조작 전에는 사운드가 재생되지 않았습니다. 시작 화면은 HTML·JS·CSS만 요청했고 브라우저 보고 전송량은 응답 헤더를 포함해 28,498 B였습니다. 소리를 끄면 배경음과 효과음이 함께 음소거되며, 다시 켰을 때 30초 배경음이 중복 재생되지 않았습니다.

## v3 · 최초 적용 기록

탑의 문지기는 대기, 힘 모으기, 치명 일격 실행, 넉다운에 맞춰 자세를 바꿉니다. 가시 적에는 돌 파편 졸개를 연결했습니다. 공격 예고 중에는 준비 자세를, 실제로 공격하거나 피해를 입을 때는 해당 자세를 잠깐 보여 줍니다. 석실은 최신 99×176 원본이며, 그림과 석실을 정수 배율로 확대하고 발 기준점(문지기 24·46, 졸개 16·38)을 같은 바닥선에 맞췄습니다. 공격 예고와 체력 뒤에 어두운 판을 댔습니다.

첫 시작 특전을 직접 선택하면 석실 배경음과 굴림 소리가 시작됩니다. 이후 굴림, 놓기, 타격, 정확히 막기, 룰렛 틱과 정지, 해금, 승리, 패배에 효과음이 재생됩니다. 상단 스피커로 배경음과 효과음을 함께 끄거나 켤 수 있으며, 사전에 두 아이콘을 추가했습니다.

캐시가 비어 있는 Edge 모바일 환경에서 `npm run build` 뒤 Vite 미리보기의 시작 특전 선택 화면을 열고 측정했습니다. 첫 화면의 네트워크 요청은 HTML·JS·CSS 3개였습니다. 그림은 전투 진입 시 석실과 해당 적에 필요한 자세를 불러옵니다. 원본 WAV의 음질과 루프를 유지했고 소리를 활성화하는 첫 사용자 조작 이후에 받습니다.

### 390×844 확인

- 시드 91에서 방패 저금을 골라 전투 UI로 보스까지 등반했습니다. 대기, 힘 모으기, 치명 일격의 짧은 공격 자세, 넉다운 순서를 확인하고 최종 승리했습니다.
- 시드 3에서 가시 적의 준비, 피격, 공격, 반격 룰렛 중 대기 자세를 확인했습니다. 시드 16의 3배 픽셀 밀도에서는 큰 칼의 예상 충전을 띄운 상태로 헤더와 조작부가 화면 안에 들어오는지 확인했습니다. 캔버스 확대 배율과 발 위치도 검사했습니다.
- 사용자 조작 전에는 음원 요청과 재생이 없음을 확인했습니다. 소리를 끈 상태에서 주사위를 놓아도 효과음이 재생되지 않았고, 다시 켰을 때 배경음이 중복되지 않았습니다. 실제 재생 이벤트로 룰렛과 해금을 포함한 전투 효과음을 확인했고, 시드 12 패배까지 진행해 패배음을 확인했습니다.
