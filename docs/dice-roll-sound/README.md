# 회귀탑 주사위 굴림과 재굴림권 해금

시드 7의 첫 전투에서 두 주사위를 다시 굴려 `1·1·1 → 3·2·1`을 만든다. 세 눈을 방어 칸에 놓고 턴을 끝내면 재굴림권이 열린다. 첫 착지는 단단한 소리 세 개, 작은 튐과 안착은 각각 한 개로 들린다. 재굴림권을 얻는 순간에는 세 칸이 차례로 밝아지며 한 음이 세 단계로 올라간다.

**재현 경로**는 첫 안내를 완료한 상태에서 `?seed=7` → 새로 하기 → 묵직한 대검 → 첫 전투 입장 → 왼쪽 두 주사위 선택 → 다시 굴리기 → 세 주사위 선택 → 방어 → 턴 끝내기다. 두 빌드 모두 규칙판 7, 보통 속도, 음악·효과음 켬으로 촬영했다. 두 번째 턴은 `5·1·2`로 시작하고 포커스는 첫 주사위에 돌아온다.

지정된 게임 기준 `a112a5c`의 구현과 첫 비교 영상은 `53758a7`에 보존했다. 위 표는 이후 격파 가독성 변경이 들어간 `134f94d`와 이를 포함한 주사위 구현 `20c50bd`의 재촬영본이다. 후보 빌드의 JS는 `index-DT_FJU_m.js`, CSS는 `index-BEuTtSRx.css`다. 시험 병합 트리에서 검사한 HTML·JS·CSS와 전용 브랜치의 빌드는 SHA-256이 각각 일치했다. ## 타이밍과 녹음

Edge의 모바일 터치 에뮬레이션에서 실제 버튼을 눌렀다. 동일한 소프트웨어 합성기와 예열한 리소스 캐시를 사용했다. 화면은 Chromium의 타임스탬프가 붙은 캡처에서, 소리는 게임의 음악·효과음 최종 출력에서 직접 받았다. AudioWorklet의 PCM과 화면 시간을 `getOutputTimestamp()`로 대응시켜 H.264 30fps와 AAC 48kHz 모노로 묶었다. [녹화 코드](capture.mjs)

채택 조건은 두 턴 각각의 대표 착지→반동이 설계값 206ms에서 40ms 이내이고, 세 착지가 서로 구별되며, 실제 해금 세 음의 간격이 100±35ms인 것이다. 완성 MP4를 다시 디코딩해 첫 착지와 세 해금음을 원본 앞부분과 대조했다. 변경 후 두 영상의 파형 상관계수는 0.989~0.998이었고, 영상에 담긴 음원 시작은 Web Audio 시작 호출보다 약 46~53ms 늦었다. 실물 스피커와 무선 이어폰의 출력 지연은 측정 범위 밖이다.

긴 프레임 반례에서는 첫 접지 전에 메인 스레드를 한 작업으로 막아 615ms에 풀었다. 390px 기준 게임은 첫 착지와 반동 여섯 소스를 622ms에 한꺼번에 시작했다. 같은 시드의 후보는 지난 접지음 0회, 1124ms에 현재 안착음 1회였고 둘 다 최종 눈은 `1·1·1`이었다. 두 화면에서 이어지는 실제 재굴림도 한 번 울렸다. 첫 착지 직후와 해금 첫 음 직후에 끊는 반례도 검사했다. ## 원음과 믹스

릴스에서 참고한 것은 순서에 맞춰 음높이가 올라가는 배치다. 회귀탑용 모서리와 반동은 새 합성음이고, 보너스는 기존 회귀탑용 합성 시안에서 한 음을 잘라 재사용했다. 세 WAV의 Git blob이 볼트 원본과 각각 일치한다. [모서리](../../public/sfx/die-corner.wav) · [작은 튐](../../public/sfx/die-rebound.wav) · [보너스 한 음](../../public/sfx/die-note.wav) · [제작 출처](../../exp/help/REPORT-ART-SOUND.md)

24kHz PCM에 게임의 게인과 재생률을 적용해 선형 합산했다. 대표 주사위 단독과 보통·빠름의 세 주사위 묶음 피크는 모두 −14.23dBFS였다. 반동 단독 피크는 −19.71dBFS, 실제 변경 후 영상 전체의 디코딩 피크는 −14.8·−14.6dBFS였다. 작가의 재질감·음량 선호는 청감 검수 대기다.

## 재검증

게임 루트에서 `npm test`, `npm run build`, `npm run smoke`, `npm run bot`을 실행한다. 비교 영상은 FFmpeg가 있는 환경에서 `node docs/dice-roll-sound/capture.mjs dist after 390`으로 다시 만들 수 있다. 세 번째 인수에 320도 사용할 수 있다. 기준 빌드는 첫 인수에 해당 빌드의 dist 경로를, 둘째 인수에 `before`를 준다. `HWIGI_SMOKE_CHANNEL=msedge`는 설치된 Edge를 선택하며 `FFMPEG`는 실행 파일의 절대 경로를 받는다.

단위 검사 185개와 타입 검사·프로덕션 빌드가 통과했다. 기존 봇의 시드 0~511을 여섯 정책으로 돌린 결과 여섯 출력 행이 기준 빌드와 일치했다. 별도로 전달받은 실제 입력 검증에서도 390px의 착지 3·반동 1·안착 1과 리사이즈 뒤 잔여음 0, 320px의 실제 해금 전 세 음 0과 해금 후 세 칸·세 음 일치를 확인했다. [봇 결과](bot.jsonl)

현재 규칙판의 자동 에고와 해금도 `node scripts/rules-six-bot.mjs safe mixed 0 64 7 detail`로 별도 비교했다. `134f94d`와 후보 모두 64판 중 50판을 완주했고, 층별 최초 에고·스트레이트 해금을 포함한 전체 JSON 출력의 SHA-256은 `8f551bcd14316529eb809a1b0c88f57d87396b7ac9f6cbf58996ee8eb6469256`이었다.

최종 병합 빌드에서 320×568·390×844의 Playwright 전건 결과는 `174 passed (10.4m)`였다. 주사위 전용 검사는 화면당 20개이며, 기존 격파 가독성과 타격별 체력 표시 검사도 전건에 포함된다. 전용 브랜치 빌드에서 PNG와 긴 프레임 기록을 다시 남긴 8개 검사도 통과했다.
