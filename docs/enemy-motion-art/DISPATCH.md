# 파세오 구현 지시 · 회귀탑 몬스터 동작

작가 승인 범위는 현재 11종과 소환 호위병 1종의 공격·피격·격파를 실제 전투에 적용하고, 보스·정예 기믹별 고유 동작을 연결하고, 모바일 결과 PNG를 남기는 일이다. 구현 주관은 파세오다. GitHub의 코드는 이 문서가 있는 아트 브랜치와 최신 origin/main을 대조해 독립 작업 브랜치에서 통합한다. 운영 배포 및 main 덮어쓰기는 범위 밖이다.

## 입력 파일

- `docs/enemy-motion-art/MOTIONS.md`, `docs/enemy-motion-art/timings.json`
- `art-source/enemy-motion/manifest.json`과 `art-source/enemy-motion/atlases/*.png`
- 기존 골렘 전용 연출은 기준 2bf3c9c에 있다.
- 앞으로 쓸 기획 양식은 저장소의 `AGENTS.md`와 `docs/monster-design-template.md`에 있다.

## 작업 단위

1. 전투 캔버스에서 정수 픽셀 배율, 공개 빌드에서 로드되는 투명 시트, 공통 발 기준점과 캐시를 마련한다. 셀 좌표는 후보 접점이며 방향과 거리는 실제 전투에서 보정한다.
2. 골렘 일반 공격·피격·격파를 먼저 실전으로 확인한다. 기존 단독 정확 방어에서 밀림 → 정지 화면의 대형 룰렛 → 전용 반격, 효과음과 체력 변화가 이어져야 한다.
3. 자물쇠·얼림·격노, 반응형·체력 비례·호위 본체·호위병, 방패병·봉인 파수꾼·철갑 기사, 12층 문지기 순으로 실제 사건을 연결한다. 12종 전부 공격·피격·격파 자세를 사용한다.
4. 보스·정예의 충전, 공격 중단과 약화, 연타, 소환·호위 선타, 봉인, 넉다운과 격파 경로를 각각 확인한다. 상태와 피해가 발생한 순간에만 해당 이펙트와 소리를 호출한다. 보스 특수 시트를 사용한다. 기믹을 빼거나 일반 타격으로 속이지 않는다.
5. 320px·390px 빌드에서 로비→전투의 실제 정상 진입과 공격·피격·격파를 재현한다. 나중 층 재현은 합법적인 게임 저장 상태로 시작해 실제 턴 해결 버튼과 실제 렌더를 쓴다. 런타임에 임의 애니메이션을 주입한 스크린샷이나 원화 합성판을 전투 증거로 사용하지 않는다. 기존 테스트·빌드·스모크도 실행한다.

## 반환

- 구현 작업 브랜치·커밋·작업 폴더, 적별 실제 경로와 확인한 이벤트, 남은 결함을 보고한다.
- 모바일에서 읽을 수 있는 390px 전후 세로 PNG를 게임 화면의 실제 캡처로 만든다. 가능하면 3장으로 나눠 일반·호위 및 기믹·정예와 문지기를 묶고, 12종의 공격·피격·격파를 모두 포함한다. 보스/정예 특수 동작은 별도 컷을 붙인다.
- 결과와 재현 스크립트는 볼트의 `wiki/projects/hwigi-remake-returns/2026-11-26-enemy-motion-implementation/`에 남긴다. 접근이 없으면 같은 자료를 구현 작업 폴더의 명시 경로에 남긴다.
- 단계마다 파일과 진짜 실행 결과를 보고하고, 검증할 수 없는 항목은 완료로 표기하지 않는다. 사용자가 말한 역할대로 파세오가 게임 코드를 구현한다.
