## 필요한 몸 그림 수

## 파세오 적용 기준

1. `art-source/enemy-motion/manifest.json`에서 각 PNG, 고정 칸 사각형, 발 기준점, 접점 후보를 확인한다. `thorns`가 사용할 시트 이름은 `golem`이다. 좌표는 각 칸의 왼쪽 위를 기준으로 한다.
2. 첫 보통 공격 접점은 현재 해결 후 152ms다. 준비·전진은 이 시각 안에 배치하고, 추가 접점은 실제 타격마다 248ms 간격으로 분리한다. `timings.json`에는 권장 예시가 있다. 피해 경로와 시간은 전투 코드 기준으로 검증한다.
3. 고정 발점을 중심으로 각 그림을 정수 픽셀 배율로 그린다. 전진과 밀림은 장면에서 처리하고, 매 컷의 그림을 몸통 길이에 맞춰 다시 늘이지 않는다. 자동으로 낸 접점 후보는 상대의 실제 칼·앞발과 만나는 화면 좌표로 보정한다.
4. 상태 표식은 적용됐을 때 한 번만 띄운다. 피해 0은 막는 자세와 연결한다. 격파 여부가 확정되면 넘어짐 뒤 바닥 자세를 잡는다. 별도 시트의 충전 중단·넉다운은 격파와 다른 복귀 순서를 쓴다.
5. 구현 단위는 골렘 일반 전투 → 자물쇠·얼림·격노 → 반응형·방패병 → 체력 비례·호위 본체·호위병 → 봉인 파수꾼·철갑 기사 → 문지기 순이다. 골렘 작업에서 기존 정확 방어·룰렛도 다시 재생한다.
6. 완료 증거는 320/390px 화면에서 성공·방어·피격·격파를 짧게 잇고, 특수기가 취소되거나 호위병이 먼저 쓰러지는 반례를 함께 기록한다. 무음으로 봐도 공격자, 접점, 밀리는 대상이 구분되어야 한다.
