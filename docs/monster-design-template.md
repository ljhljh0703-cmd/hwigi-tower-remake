## 실제 전투 검증

- 몬스터별 기본 공격, 피격, 격파의 정상 경로와 주요 기믹의 성공 또는 취소 반례를 적는다.
- 모바일 320px·390px에서 캐릭터와 접점이 잘 읽히는지, 연타 횟수·막힘·피해·소리가 맞는지 확인한다.
- 캔버스를 게임 빌드에서 캡처한다. 시드·전투 상태·발생한 실제 이벤트와 함께 읽을 수 있는 세로 PNG를 첨부한다.
