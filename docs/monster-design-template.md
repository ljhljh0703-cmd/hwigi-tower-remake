### 같은 입력으로 두 판 비교하기

| 화면 | 시드·배치·속도 / 바꾼 변수 하나 | 기대한 장면과 실패 반례 | 전후 접촉·후속 PNG / 관측값 |
| --- | --- | --- | --- |
| 320×568 | | | |
| 390×844 | | | |

정지 중에는 카메라 이동을 뺀 발·타점·첫 파편의 좌표를 대조한다. 해제 뒤 첫 후속 컷, 카메라의 0 복귀, 실제 체력·소리 순서를 확인한다. 같은 재질은 같은 입력에서 같은 모양으로 재현하고, 재질 비교에서는 같은 피해와 경과 시간을 쓴다. 피해 0, 호위 대타, 연타, 격파·패배 중 해당하는 반례를 고른다.

## 실제 전투 검증

- 몬스터별 기본 공격, 피격, 격파의 정상 경로와 주요 기믹의 성공 또는 취소 반례를 적는다.
- 모바일 320px·390px에서 캐릭터와 접점이 잘 읽히는지, 연타 횟수·막힘·피해·소리가 맞는지 확인한다.
- 캔버스를 게임 빌드에서 캡처한다. 시드·전투 상태·발생한 실제 이벤트와 함께 읽을 수 있는 세로 PNG를 첨부한다.

### 격파 가독성 검증표

| 항목 | 합격 조건과 증거 |
| --- | --- |
| 접촉과 정보 우선순위 | 실제 타격 때 체력·피해 숫자·접촉 자세·소리가 한 번씩 맞는다. 320×568과 390×844 전체 화면에 대상별 체력과 피해량이 함께 들어오고 숫자 좌우에 각각 4 CSS px 이상 남는다. 인접 체력 카드 사이는 2 CSS px 이상 둔다. |
| 숫자와 파편 | +112·136·160·340ms의 불투명 조각과 피해 글리프 겹침 0px. 실제 스크린샷에서 숫자를 숨긴 차분에 글리프가 남아야 한다. 자동 회귀에서는 글리프보다 넓은 실제 DOM 사각형과 파편 마스크를 대조한다. |
| 원화와 배경 | 시드 12 둘째 턴에서 조각과 그 뒤 장면의 밝기 차가 20 이하인 불투명 픽셀 비율을 구한다. 112·136·160ms 각각 공개 기준보다 낮고 평균 감소가 10%p 이상이어야 한다. 그다음 원본 크기로 돌의 면, 이음새, 깨진 단면, 벽돌 줄눈을 본다. 전장을 어둡게 덮거나 전둘레에 검은 테를 두른 후보는 반려한다. |
| 비행과 착지 | 순서대로 붙은 몸 → 벌어진 틈 → 서로 다른 궤적 → 바닥 접촉 → 고정된 잔해가 보인다. 정상 속도에서 시선이 타점에서 잔해까지 이어지는지 확인한다. +211ms에는 면적 12 CSS px² 이상, 배경 대비 2:1 이상인 픽셀이 20% 이상인 독립 덩어리가 셋 이상 보인다. 착지 후 두 컷은 같은 위치에 남고 보상 진입이 가능하다. |
| 반례 | 다른 층의 벽·재질, 3인 호위 대타 및 남은 적의 예고, 골렘 정확 방어·룰렛 정지·반격, DPR 2 빠름, 무음·동작 줄이기, 격파와 해금이 겹친 턴을 실행한다. 동작 줄이기에서는 기존 해금 대기 동안 숫자와 정지 잔해를 남기고 대기가 끝나는 즉시 전환한다. |
| 인계 | 기준판·검토판 커밋 또는 JS/CSS 해시, 시드·배치·속도·DPR, 원본 크기의 접촉·비행·착지·반례 PNG와 관측값, 이전판 실패와 후보 성공, 독립 검토 상태를 기록한다. |

검토판과 기준판 모두 같은 검사 파일을 사용한다. `npm run build` 뒤에 `npm run smoke -- "defeat-readability\.spec\.mjs"`를 실행한다. `HWIGI_DEFEAT_REPORT`를 지정하면 전체 화면 PNG와 프레임별 JSON을 저장한다. `HWIGI_SMOKE_DIST`로 비교할 이전 빌드 폴더를 지정할 수 있다. [2026-11-28 격파 사례](../_return/2026-11-28-defeat-readability/RETURN.md)
