# 회귀자는 탑을 오른다 · 공개판 화풍 통일

기준은 `f84d495`, 작업 브랜치는 `codex/art-font-unify`다. 아래 PNG는 배포용 빌드를 Edge Chromium에서 열어 터치로 진행한 화면이다. 전후 비교는 같은 크기에서 왼쪽이 기준판, 오른쪽이 적용판이다.

## 적용 결과

- 석재 팔레트와 기본·눌림·선택 석판을 로비, 전투, 갈림길, 시작 특전, 보상과 대화상자에 적용했다. 일반 주사위 면 `#d5cec0`과 활성 「턴 끝내기」 배경 `#b04d3e`는 실전 화면에서 확인했다.
- 기존 아이콘 ID 79개를 같은 뜻의 픽셀 도안으로 연결했다. 홀수 3눈과 짝수 2눈, 세 눈 조합, 봉인 주사위는 기존 의미가 바로 읽히도록 도안을 따로 맞췄다. 키트에 없는 기절·갑옷 파괴·반사·호위 퇴장·겹친 주사위·왕관·왕홀은 기존 도형을 같은 팔레트로 픽셀화했다. 예고·기믹 관련 23개를 12·13·14·16·20·24·32px에서 렌더링해 원본보다 가로 또는 세로가 줄어든 도안이 없음을 확인했다.
- 배경은 1–4층, 5–8층, 9–12층에 따라 전장 캔버스에 그린다. 각 이미지의 204행을 기존 발 기준 높이에 맞췄다. 두 크기에서 골렘, 쇠사슬 집행관, 호위가 나온 전투와 마지막 보스의 머리·무기·발 윤곽을 대조했다.
- 제목과 주요 숫자는 갈무리11 굵게 2.40.4를 적용했다. 320px 도감 본문 13.44px의 같은 문장에 세 후보를 적용해 비교했을 때 갈무리11과 물마루는 작은 한글의 속공간과 획 사이가 좁아졌고, Neo둥근모 16px 기준 도안은 같은 크기에서 획이 불균일하게 보였다. 본문은 기존 시스템 글꼴을 유지했다. 설정의 「갈무리11 글꼴 라이선스 (SIL OFL 1.1)」를 두 크기에서 눌러 동봉 원문이 열리는 것을 확인했다. ## 검증

- `npm run build` 성공. 결과물을 `/hwigi-tower-remake/` 아래에서 구동해 그림·글꼴·라이선스 경로를 확인했다.
- `npm test` 153개 통과. `npm run smoke` 32개 통과(320×568, 390×844 각 16개). 가시 골렘의 단독 정확 방어, 전신 자세 정지, 효과음, 룰렛과 피해 시점, 움직임 줄이기의 자동 반격을 포함한다.
- `npm run bot` 표준 출력은 양쪽 모두 1,266바이트이며 바이트 단위로 일치했다. SHA-256은 `f3406e44431762fd4a5dfc9e419d712cee9d450b65fed9d5243593e09a59e416`이다.
- 새 등반부터 1층 승리, 보상 선택, 2층 갈림길까지 이어서 확인했다. 체력 1에서 공격해 패배하는 반례도 재현했다. 상점·휴식·이벤트에서 카드를 각각 선택해 설명과 버튼이 뷰포트 안에 있는지 확인했다.
