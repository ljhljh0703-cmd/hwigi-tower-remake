# 회귀탑 상층 전투 인계

공개판 기준은 `a112a5c`다. 새 등반은 12층 보스를 쓰러뜨리면 **13층으로** 또는 **등반 마치기**를 고른다. 13층으로 이어 가면 체력, 동전, 아이템, 족보와 유물(6층 보스 유물 포함)을 가져간다. 기존 형식 2 지도 저장은 원래 지도와 후보를 복원하고 12층에서 결산한다.

상층에서는 표적 선택 없이 현재 전위부터 직접 공격과 룰렛 반격을 받는다. 남은 피해는 뒤 적들에게 순서대로 이어진다. 적별 예고와 지원, 14층 교대, 19층의 준비·강타·회복을 같은 전열 계산에서 처리한다. 배치 중 방어 목표는 직접 공격에서 살아남을 적의 타격만 더한다. 정확 방어 룰렛은 첫 표적과 관통 순서를 저장한다. 결과와 아이템 소모를 확정한 뒤 연출을 재생한다.

16층에는 치료 도구와 등급별 유물 후보가 있으며 한 번 살 수 있다. 하층의 구매 영수증과 구분된다. 19층에서 하층·상층 완주를 표시하고 첫 인장을 로비에 기록한다. 다음 등반의 첫 휴식에 상층 완주 회고가 한 번 나온다.

전위와 후위 위치는 캔버스 폭의 47%, 69%, 90%를 사용한다. 후위 발판은 320×568에서 24px, 390×844에서 30px 올린다. 실제 원화는 정수 배율로 그리고 타격·지원·격파와 회복에 기존 전투음 및 그림을 사용한다.

## 빌드와 회귀

- 구현 검증 커밋은 `b3bebab`이다. Windows 배포 빌드의 자바스크립트는 `index-Io9VfsMS.js`, CSS는 `index-x7TiFcwv.css`다. SHA-256은 각각 `ef067e1097059bc21fdb8eec20984bdc441bd6e22ce6df7236af83be0e2cb3eb`, `2b221ae6d2eb6b8cd4f38dbf7c444c184fa2e80148c1b909e305d5f0e44f20de`다.
- 단위 테스트 196개가 통과했다. Windows 전체 스모크의 첫 병렬 검증에서 골렘 룰렛의 가상 시각 읽기가 두 기기에서 어긋났다. 테스트 시계를 입력 전에 정지하고 8ms씩 진행해 접촉과 체력을 확인하게 바꿨다. 최종 상층·격파·골렘 스모크 38개와 이어하기·인장 회고를 포함한 상층 재실행 6개가 통과했다.
- `a112a5c` 배포 빌드와 후보의 가시 골렘 단독전에서 정확 방어와 룰렛 뒤 체력 20·1인 반격 접점 검사가 각각 4개 통과했다. 후보에서는 정지된 전장, 룰렛 잠금과 반격의 피해·파편·소리 순서를 두 크기에서 다시 확인했다.
- 작업 브랜치에서 Noto CJK를 설치하고 한글 글꼴을 조회했다. Linux 빌드와 단위 테스트 196개, Chromium 스모크 140개가 통과했다. Windows의 시드 7 재생에서는 배포본의 Galmuri11 로딩을 확인했다. [Linux 스모크](https://github.com/ljhljh0703-cmd/hwigi-tower-remake/actions/runs/46127586415)
- 상층은 기존 시트를 이용한 임시 원화 상태다. 공개 반영 전 독립 검토가 남아 있다.

## 등반 봇

하층은 공개판의 보수·강적 우선 경로와 규칙판 7 아이템 선택을 썼다. 상층은 같은 12층 승리 체크포인트를 복제해 전량 관통과 전위까지만 닿는 경우를 재생했다. 합법적인 일반 주사위 배치를 전수 비교하고 에고의 가능한 눈을 평균했다. 눈이나 룰렛 결과는 확정 전 선택에 쓰지 않았다. 조율, 재굴림, 보상과 룰렛 선택에는 기존 정책을 사용했다.

두 시드 구간에서 경로와 해금 수를 바꿔 32,768개 시작 조건을 비교했다. 8개 코호트에서 공개판과 후보의 1~12층 층별 도착·패배·턴 수, 방별 전투 체크포인트·족보·구매 기록 SHA-256이 일치했다. 새 등반의 12층 결산에서는 이어서 쓸 동전을 보관한다.
