# 네온 최종 검토 승인 항목 반영

기준 커밋은 `codex/ego-auto`의 `f2c7575`다.

| 항목 | 변경 |
| --- | --- |
| 아이템 | 상단 유물은 설명을 연다. 전투에서 쓰는 아이템은 주사위 위 엄지 띠에 모았다. 켜기형은 한 번 눌러 토글하고, 대상형은 바로 주사위를 고른다. 선택지는 전장 위에 떠서 전장 높이를 유지한다. 쇠쐐기는 빚진 모래시계와 다른 그림을 사용한다. |
| 새긴 동전 | 첫 결과를 확인하고 다시 돌린다. 두 피해 중 큰 결과가 남고, 동전 사용과 남긴 결과를 이어 할 수 있다. |
| 전투 정보 | 상단에 특전과 턴을 표시하고 특전을 누르면 설명을 띄운다. 전투 체력은 전장에 표시한다. 적 이름과 방어 목표를 상시 표시하고, 도감 보상·유물 목록을 합쳤다. 첫 기믹 안내는 누르거나 턴을 끝낼 때 닫힌다. |
| 상점·보상 | 규칙판 7 상점에 일회용품 한 품목을 추가했다. 동전이 충분하면 서로 다른 품목을 연속 구매하고 ‘떠나기’로 나간다. 신규 상품은 기존 치료 도구와 같은 2동전으로 정했다. 카드에 효과 문구를 한 줄로 표시한다. |
| 12층 지도 | 갈림길 상단에서 실제 경로, 현재 위치, 상인·강적·휴식·보스를 펼쳐 볼 수 있다. |
| 반격 룰렛 | 기본은 눌러 시작하고 다시 눌러 감속·정지한다. 설정에서 자동 진행을 켤 수 있다. 결과는 시드로 결정된다. 에고가 잠든 동안 합공 칸에는 단독 피해를 표시한다. |
| 위기 각성 | 규칙판 7의 위기 확률 각성을 제거했다. 앞선 규칙판은 각각의 기존 전투 규칙으로 이어진다. |

## 규칙판 7 봇 완주율

경로·시드·영구 해금 조합당 4,096판을 실행했다. 봇은 같은 시드의 룰렛 결과를 적용하고, 상점에 머무는 동안 정책에 따른 추가 구매를 한다.

| 경로 | 시작 시드 | 영구 해금 | 기준 | 변경 후 | 차이 |
| --- | ---: | --- | ---: | ---: | ---: |
| 보수 | 8192 | 미해금 | 72.80% | 72.85% | +0.05%p |
| 보수 | 8192 | 10장 | 70.17% | 70.65% | +0.49%p |
| 보수 | 12288 | 미해금 | 71.36% | 71.90% | +0.54%p |
| 보수 | 12288 | 10장 | 68.31% | 69.02% | +0.71%p |
| 강적 우선 | 8192 | 미해금 | 63.13% | 65.38% | +2.25%p |
| 강적 우선 | 8192 | 10장 | 63.21% | 64.99% | +1.78%p |
| 강적 우선 | 12288 | 미해금 | 63.11% | 66.04% | +2.93%p |
| 강적 우선 | 12288 | 10장 | 63.72% | 64.82% | +1.10%p |

최대 상승폭은 +2.93%p였다. 룰렛의 시작·정지 입력은 시드 결과를 바꾸지 않는다.

## 검증

- 빌드와 단위 테스트 185개가 통과했다. 모바일 스모크는 320×568·390×844에서 총 98개가 통과했다.
- Windows Headless Chromium `159.0.8154.6`에 Ubuntu 패키지 `fonts-wqy-zenhei` `0.9.45-8build1`의 한글 글꼴을 적용한 조건에서도 스모크 98개가 통과했다. 브라우저에서 실제 글리프 사용을 확인했다.
- 아이템 조작 창을 열거나 주사위를 골라도 전장 크기가 동일했다. 새긴 동전의 두 번째 결과가 첫 결과보다 낮은 시드에서도 큰 피해가 적용됐다. 규칙판 7의 위기 시드에서 체력 6과 정확 방어가 유지됐다.
- 가시 골렘의 전신 자세, 룰렛 시작부터 정지까지 전장 고정, 효과음 순서와 룰렛 정지 뒤 반격 피해 적용을 재검증했다.
