# 공개 전 최종 수정

작업 브랜치 `codex/integrate-1127`의 기준 커밋은 `65e0a31`이다.

| 항목 | 변경 및 재현 |
| --- | --- |
| 해금 조건 | 두 예시 아래에 ‘이어지는 눈 셋 · 순서 무관’ 또는 ‘같은 눈 셋’을 표시했다. 공격·방어 양쪽의 예시 눈과 실제 해금을 확인했다. |
| 아이템 사용 막대 | 기호 요약 아래에 기존 아이템 설명의 첫 문장을 한 줄로 표시한다. 넘치는 부분은 말줄임 처리한다. 빚진 모래시계와 조율 잔편을 골라 설명과 사용을 확인했다. |
| 첫 판 방어 화살표 | 강조된 주사위에서 두 칸 사이로 내려가 방어 빈칸 가운데에 닿는다. 경로가 공격 합 숫자와 ‘방어’ 제목을 통과하지 않는지 확인했다. |
| 첫 판 반격 | 직접 눌러야 하는 첫 판에 ‘정확히 막았습니다! 반격 룰렛을 누르세요.’를 표시한다. 에고가 잠들어 있을 때 ‘합공 잠김 · 피해 적용’을 표시한다. 6·8칸도 일반 반격 피해로 뽑히는 기존 규칙에 맞춰 범위 `1–8`을 유지했다. |
| 상단 띠 | 등반 중 상단 띠를 체력·동전·층 순서로 통일하고 층을 `1/12 층` 형식으로 표시한다. 층 선택, 전투, 보상과 등반 실패 화면을 확인했다. 12층 전투에서 동전 18개와 체력 22/22를 표시하고 로비 버튼부터 설정 버튼까지 겹침이 없는지 확인했다. |
| 설정 확인창 | ‘새 표식 기록’을 ‘새 카드 표시 기록’으로 바꿨다. 취소 후 기존 해금 기록이 유지되는지 확인했다. |

## 검증

- 빌드, 단위 테스트 180개, 320×568·390×844 모바일 Edge 스모크 84개가 통과했다.
- `npm run bot`과 규칙판 7 봇 출력은 `65e0a31`과 바이트 단위로 같았다. 규칙판 7은 보수·강적 우선 경로, 시작 시드 8192·12288, 미해금·10장 해금의 8개 조합에서 4,096판씩 돌렸다.
- 골렘 단독 정확 방어의 전신 자세, 전장 정지, 효과음, 룰렛 정지 뒤 피해 적용을 기존 스모크에서 재검증했다.
- 에고가 잠든 상태에서 룰렛 6과 8을 각각 뽑아 일반 반격 피해로 적용되는 것을 두 크기에서 확인했다. 12층 상단 띠는 동전과 층 표시 사이의 간격도 확인했다.
