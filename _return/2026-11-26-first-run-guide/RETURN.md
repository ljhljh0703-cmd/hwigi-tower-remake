# 회귀탑 리메이크 첫 판 안내

첫 새 등반의 1층에서 **공격 칸에 배치 → 턴 끝내기 → 정확 방어와 반격 룰렛**을 한 줄씩 안내한다. 화면에서 시드 `7210`으로 첫 두 턴의 첫 굴림 `[6, 4, 2]`, `[3, 4, 6]`을 만든다. 첫 공격 뒤 `5 + 4`로 예고되는 적 공격을 주사위 `3`과 `6`으로 막는다. 지도, 재굴림, 반격 룰렛, 보상, 이후 층에는 기존 등반의 시드를 쓴다.

안내 밖 빈 곳을 누르거나 `건너뛰기`, `Esc`로 안내를 닫을 수 있다. 설정의 `안내 다시 보기`를 누르면 다음 새 등반에서 안내가 열린다. 진행 중인 저장을 유지하기 위해 현재 등반은 그대로 이어진다. 움직임 줄이기에서는 손가락과 화살표가 정지한다. 터치로 주사위를 끌어 놓거나, 주사위와 칸을 차례로 누르거나, 키보드 `Tab`과 `Enter`로 배치할 수 있다.

같은 눈 셋·이어지는 눈 셋을 놓을 수 있을 때, 다섯 기믹의 예고가 각각 처음 표시될 때, 전투 보상·갈림길·상인·중간 보스 유물 화면에 처음 들어갈 때 아이콘과 한 줄을 표시한다. 한 번에 한 말풍선이 표시되며 1.5초 뒤 또는 누르면 닫힌다. 본 항목은 브라우저에 저장한다.

## 첫 공격까지

저장 기록이 없는 헤드리스 Edge에서 페이지를 연 순간부터 적 체력이 6 줄어드는 순간까지 쟀다. 지도와 보상을 재현하기 위해 등반 시드 `10`을 썼고 보통 연출을 켰다. 아래 시간은 자동 터치로 측정한 값이며 사람의 읽기·판단 시간은 포함하지 않는다.

## 검증

- `npm ci`, `npm test` 153개, `npm run build`, `npm run smoke` 16개 통과. 모바일 화면 검사는 `HWIGI_SMOKE_CHANNEL=msedge`로 헤드리스에서 실행했다.
- `npm run bot`의 표준 출력 전체를 `a10212b`의 깨끗한 소스에서 실행한 출력과 바이트 단위로 비교했다. SHA-256은 `F3406E44431762FD4A5DFC9E419D712CEE9D450B65FED9D5243593E09A59E416`이다.
- 두 모바일 크기에서 실제 로비부터 1층 전투, 반격 룰렛, 1층 보상, 2층 갈림길과 기믹까지 진행했다. 방어에 `4`를 잘못 놓았다가 도로 빼고 `3 + 6`으로 정확 방어하는 경로와, 안내 도중 새로고침해 키보드로 룰렛까지 도달하는 경로를 확인했다. 터치 드래그, 빈 곳 터치, `Esc`, 설정의 다시 보기도 확인했다.
- 보상·상인·보스 유물·해금·기믹의 첫 표시와 재진입 시 재표시 방지를 검사했다. 등반 시드 1,024개에서 두 첫 적과 제공 특전·서약의 조합 3,624개를 규칙 함수에 넣어 안내대로 배치하면 둘째 턴에 정확 방어가 되는 것을 확인했다.
