# PC 상층 전위·후위 배치

`codex/polish-1129`의 이전판 `1f0fdb4`와 수정판 `fa1e226`을 시드 12의 같은 저장에서 비교했다. 회귀자는 기존 6배 정수 배율과 전위 바닥선을 유지한다. PC 일반 전위는 8배, 후위는 6배, 호위가 쓰러진 뒤 전위에 선 창살의 죄수는 7배다.

| 17층 세 마리 | 180px | 125 → 200px | 100 → 150px |
| 19층 보스와 호위 | 180px | 125 → 200px | 104 → 156px |

수치는 두 PC 해상도에서 같은 대기 자세의 불투명 픽셀 높이다. 후위 발판을 전위 바닥보다 1440×900에서 270px, 1920×1080에서 324px 높였다. 적 이름표와 체력도 각 발판 아래로 함께 이동했다. 1050×680에서는 위아래 단이 가로 공간을 나눠 쓰도록 배치했고, 적과 이름표가 겹치지 않는 것을 확인했다. [좌표 수정 전](geometry-before.json) · [수정 후](geometry-after.json)

## 검증

- 320×568 및 390×844에서 13·17·19층과 19층 보스 단독을 전후 비교했다. 두 화면 모두 전장 픽셀과 회귀자·적·이름표 좌표가 일치했다.
- 두 PC 해상도에서 13층을 정상 속도로 두 턴 진행했다. 전위 피해 10과 격파, 후위로 이어진 피해 2와 전진, 다음 턴 피해 10을 확인했다. 19층 보스 단독 격파 재생에서 피해 13과 회귀자의 바닥선을 확인했다.
- 빌드, 단위 테스트 197개, Chromium 상층·패널 스모크 20개가 통과했다. PC 스모크는 두 해상도에서 13·17·19층의 전위와 후위 높이, 바닥선, 실루엣 겹침을 검사한다.
- 리눅스에서 Noto Sans CJK KR을 확인한 뒤 전체 Chromium 스모크 198개가 통과했다. [리눅스 검증](https://github.com/ljhljh0703-cmd/hwigi-tower-remake/actions/runs/46171296841/job/141060085117)
- 1~19층 등반 봇 4,096회를 다시 실행했다. 층별 결과와 하층 플레이 지문이 이전판과 일치했고, 출력 전체의 SHA-256은 `450499c6ef7878631701b60801ca6739d03d678b62bab51f2791209d41d4be64`였다. [이전 검증의 봇 결과](../2026-11-29-polish-2/bot-comparison.json)
