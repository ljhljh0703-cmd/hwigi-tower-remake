# 작가 확정 이름 반영

규칙판 7의 아이템·시작 특전·해금 카드 43개, 적 13종, 구역 3곳을 정본과 대조했습니다. 「간격자」와 정본의 유지 항목은 기존 이름을 씁니다. 이전 규칙판 1~6의 저장을 열면 해당 규칙판의 이름을 표시합니다.

적의 이름·칭호·출신·설정·구역과 구역의 층 범위·분위기를 `src/enemy-codex.ts`에서 읽습니다. 도감의 구역은 각 적의 설정상 소속입니다. 층에 들어갈 때 구역명을 함께 표시하며, 전투와 지도 미리보기에는 새 적 이름이 나옵니다. 층 제목은 일반 연출에서 620ms, 움직임 줄이기에서 380ms 동안 표시합니다.

## 검증

- 빌드와 단위 테스트 185개, Playwright Chromium 모바일 스모크 100개가 통과했습니다. 실제 갈림길에서 4층에 들어가고, 전투·도감·보상에서 새 이름을 검증했습니다. 규칙판 5·6 저장은 기존 이름으로 복원됐습니다.
- Ubuntu 패키지의 WenQuanYi Zen Hei 글꼴을 적용한 Windows Chromium에서도 스모크 100개가 통과했습니다. 320px 보스 보상 검사는 중심 위치의 허용치를 픽셀 단위로 올림하고, 패널 전체가 화면에 들어오는지도 확인합니다.
- 규칙판 7 봇은 안전·강적 경로, 시드 시작값 8192·12288, 영구 해금 0·10장의 8조건에 4,096등반씩 실행했습니다. 모든 상세 JSON과 일반 `npm run bot` 출력이 이름 변경 전후 바이트 단위로 일치했습니다.
