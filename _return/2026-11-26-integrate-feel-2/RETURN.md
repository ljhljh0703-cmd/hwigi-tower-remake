# 회귀탑 게이머 검수 반영

`integrate-feel`의 `cfff0e6`에 `origin/main`의 `fe7e656`을 병합했다. 첫 판 안내, 첫 기믹의 조건·효과 안내, 연타 피해 표시는 main의 동작을 적용했다. 회귀자 동작, 타점과 효과음, 골렘 전장 룰렛, 게임 오버, 특전 카드는 통합 브랜치의 구현을 이어 쓴다.

| 항목 | 결과 |
| --- | --- |
| 첫 판 안내 | 공격 배치부터 턴 종료, 정확 방어와 직접 룰렛, 보상, 갈림길, 첫 기믹까지 터치로 진행했다. 키보드, 이어 하기, 건너뛰기, 다시 보기와 처음에만 뜨는 해금·상인·보스 유물 안내도 확인했다. 안내 중에는 룰렛 버튼을 직접 누르며 일반 전투에서는 기존처럼 자동으로 이어진다. |
| 공격 숫자 | 시드 12의 첫 턴에서 `7 + 2`는 적 공격 두 타이고, `−12`는 회귀자가 적에게 준 피해다. `적 공격 7 + 2`와 `적 −12`로 구분했다. 실제 체력은 적 23→11, 회귀자 22→13이다. |
| 연타 칩 | 아직 닿은 타격이 없을 때는 칩을 숨긴다. 1타가 닿으면 `1턴 내 피해`와 7, 2타가 닿으면 2가 추가된다. 방어한 타격은 예고에서 실제 피해로 바뀐 값을 표시한다. 첫 기믹으로 넘어가는 전투의 `3→0`, `3→1`, `2`를 확인했다. |
| 특전 | 제목 아래 `이번 등반에 쓸 특전을 하나 고르세요.`를 넣고 카드 목록을 올렸다. 두 해상도에서 첫 카드가 화면 높이 40% 위에 있고, 세 카드를 스크롤 없이 고를 수 있다. |

## 검증

- `npm run build`가 성공했다. `npm test` 153개와 320×568·390×844 헤드리스 Edge의 `npm run smoke` 32개가 통과했다.
- `npm run bot` 출력 1,266바이트가 규칙판 6 기준 `a10212b` 및 병합한 `fe7e656`과 일치했다. SHA-256은 `F3406E44431762FD4A5DFC9E419D712CEE9D450B65FED9D5243593E09A59E416`이다.
- 320px 호위전에서는 첫 기믹 안내가 확보한 위쪽 여백 때문에 적 공격 예고가 회귀자 실루엣을 가렸다. 짧은 기믹 소개 전장의 발판과 체력 표시를 조정하고, 세 인물과 예고·체력·주사위의 비겹침을 다시 확인했다.
- 사진은 실제 화면의 터치 조작에서 촬영했다. 공격 사진은 칼끝이 닿아 적 체력이 줄고, 적의 첫 연타가 들어오기 전 장면이다.
