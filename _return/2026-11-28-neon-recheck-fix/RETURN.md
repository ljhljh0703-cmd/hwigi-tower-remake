# 네온 화면 재검토 반영

## 화면 변경

- 아이템 창을 전장 위쪽에 배치해 체력과 주사위를 보면서 대상을 고를 수 있습니다. 설명은 줄바꿈하며, 대상 진행은 「주사위 1/1 선택」처럼 표시합니다. 엄지 띠의 유물은 보라색, 일회용품은 회색이고 보유량과 효과값을 따로 표시합니다. 소진된 일회용품을 바로 걷어냅니다.
- 에고가 잠들었을 때 룰렛 합공 칸은 어두운 색으로 구분하고, 안내에 「피해 1–8 · 에고 깨어나면 6·8 합공」을 표시합니다. 시작·정지 버튼을 하단에 두고, 은화로 재회전한 뒤 실제 적용 수치가 들어간 「피해 N 주기」 버튼을 표시합니다.
- 해금 진행 칩에는 「같은 눈 하나 더」 및 「이어지는 눈 하나 더」와 필요한 눈을 표시합니다. 두 눈이 가능하면 「3 또는 6」으로 표시합니다. 두 조건에 모두 해당하는 주사위는 위·아래 테두리로 구분합니다.
- 회귀자 어깨 뒤로 옮긴 에고는 탭하면 설명이 열립니다. 자동 배치 꼬리표는 에고 위에 표시합니다. 첫 신호와 각성 대사에는 눈 아이콘이 붙고, 잠긴 자리 위의 「에고 각성!」은 1초 동안 표시합니다.
- 보상과 보스 유물 카드의 요약은 줄바꿈하고 유물의 대가까지 적었습니다. 상점에는 반감 전후 회복량과 보유 유물 슬롯을 표시합니다.
- 12층 지도 범례에 전투와 이벤트를 추가하고, 통과한 층의 미방문 방을 흐리게 표시합니다. 특전 말풍선은 이름표 옆 공간에 띄웁니다. 기믹 안내에 공격·방어 칸을 명시하고, 보스 유물 칩과 적 이름표 사이에 간격을 확보했습니다.
- 적 도감에 대기 초상화와 기믹 설명을 추가했습니다. 아이템 도감에는 약초 꾸러미의 상점·휴식 회복량을, 주사위 도감에는 에고 해금·자동 배치 기준을 정리했습니다.

## 검증

- 빌드와 단위 테스트 185개를 통과했습니다.
- Playwright Chromium 모바일 스모크 100개가 기본 글꼴과 Ubuntu 패키지 WenQuanYi Zen Hei 글꼴을 적용한 Windows Chromium에서 각각 통과했습니다. 두 화면 크기에서 아이템 설명·선택지가 한 화면에 들고 체력 바와 겹치지 않는지 검사했습니다.
- 가시 골렘의 정확 방어 접촉 자세, 룰렛 동안의 전장 정지, 효과음과 반격 피해 정산 순서를 회귀 검사했습니다.
- 기준 `002be5f`와 `npm run bot` 출력이 일치했습니다. 규칙판 7은 안전·강적 경로, 시드 시작값 8192·12288, 영구 해금 0·10장의 8조건을 조건당 4,096등반씩 실행했습니다. 상세 JSON 8개가 바이트 단위로 같았습니다.
