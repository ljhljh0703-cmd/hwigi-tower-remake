# 회귀탑 공개판 개발 정리

작업 브랜치는 `codex/dev-cleanup`이며 기준 커밋은 `fd2778c`입니다.

## 반영 내용

- 반격 룰렛은 처리 중 재입력을 막고 `finally`에서 입력 잠금을 풉니다. 연출 중 예외가 나도 저장한 반격 결과나 선택 대기 상태를 화면에 복원합니다. [룰렛 잠금](../../src/counter-roulette.ts) · [반격 화면 복원](../../src/main.ts)
- 도감은 열 때마다 현재 등반의 규칙판을 읽습니다. 로비와 규칙판 6 등반에서는 옛 기믹을 숨기고, 규칙판 1~5 저장을 이어 하는 동안에만 표시합니다. 지도 도입 전 저장은 규칙판 1과 같은 도감을 씁니다. [도감](../../src/battle-guide.ts) · [저장 복원](../../src/ascent-save.ts)
- GitHub Free의 비공개 전환 시 Pages 게시 해제, 현재 워크플로의 공개 저장소 조건, 전환 전 확인할 요금제·대체 호스팅·도메인 DNS를 배포 절에 적었습니다. [README 배포 절](../../README.md#배포) · [Pages 워크플로](../../.github/workflows/pages.yml)

## 도감과 규칙판 6 코드 대조

`generateAscentMap(seed, 6)`을 시드 0~4095에서 생성해 배치 가능한 적 12종을 찾았습니다. 각 적의 1~20턴에서 `enemyIntentAt`으로 선택되는 공격과 동작을 확인하고, 전투 중 생기는 상태와 조건부 기믹을 코드에서 대조했습니다. [지도와 적 선택](../../src/ascent-map.ts) · [적 행동표](../../src/enemy-roster.ts) · [전투 중 기믹](../../src/yacht-combat.ts)

## 검증

- `npm run build` 성공. `npm test` 155개 통과. 새 룰렛 단위 테스트에서 회전 함수가 던진 예외, 회전 중 중복 진입 차단, 예외 뒤 재진입을 확인했습니다.
- 헤드리스 Edge에서 `npm run smoke` 36개 통과. 320×568 및 390×844에서 로비의 새 등반과 규칙판 5 저장의 이어 하기로 도감을 열었습니다. 규칙판 5 저장이 있는 로비에서도 옛 기믹이 숨겨졌습니다. 규칙판 1~5 전체의 도감 항목은 단위 테스트로 확인했습니다.
- 두 화면 크기에서 가시 골렘 단독 정확 방어의 전신 포즈, 전장 정지, 룰렛 효과음 순서, 결과 표시 뒤 적 피해 발생을 확인했습니다. 회전과 결과 표시 중 적 체력이 줄지 않는지 추가한 검사까지, 룰렛 스모크 4개가 재실행에서 통과했습니다. 회전 애니메이션에 예외를 넣었을 때 다음 턴의 도감과 로비 조작이 가능했고, 다시 이어 해도 피해가 한 번만 반영됐습니다.
- `npm run bot` 표준 출력은 `fd2778c`와 1,266바이트 전체가 일치했습니다. SHA-256 `f3406e44431762fd4a5dfc9e419d712cee9d450b65fed9d5243593e09a59e416`.
