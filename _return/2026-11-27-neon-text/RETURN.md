# 네온 문구 윤문 반영

기준 커밋 `5741d89`에 [작가 승인 적용표](apply-neon.csv)의 119행을 적용했다. 대상 8개 파일에서 119곳을 교체했다. **찾지 못한 원문은 0건이다.** 도감의 두 짧은 원문이 구판 설명의 앞부분에도 들어 있어, 긴 원문을 먼저 대조해 두 버전의 적용문을 각각 반영했다.

`${…}` 자리와 수치를 대조했다. 적용표에서 ‘한 번’을 ‘1회’로, ‘한 장’을 ‘1장’으로 바꾼 곳은 같은 수량을 표시한다. 문구를 비교하는 단위 테스트와 스모크의 기대 문구를 갱신했다. 결과 화면의 제목은 ‘등반 실패’다.

## 검증

- 빌드, 단위 테스트 180개, 모바일 Edge 스모크 84개가 통과했다.
- `npm run bot`과 규칙판 7 봇의 전체 출력이 기준 커밋과 일치했다. 규칙판 7은 보수·강적 우선 경로, 시드 8192–12287·12288–16383, 미해금·10장 해금 조합으로 총 8번 실행했다. 각 조합은 4,096판이다.
- 320×568과 390×844에서 첫 판 안내, 도감, 보상, 상점, 등반 실패, 설정 확인창을 열었다. 320×568에서 문구와 버튼에 가로 넘침이나 잘림이 없었다. 설정 확인창은 취소로 닫았다.
- 320×568에서 반격 안내 문장을 한 줄로 표시하고 ‘건너뛰기’ 버튼을 그 아래에 뒀다. 적 기믹 도움말은 작은 화면의 여백과 글자 크기를 조정해 길어진 넘어뜨리기 설명까지 한 줄에 표시했다.
