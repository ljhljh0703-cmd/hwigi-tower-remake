# 공개 전 main 병합

작업 브랜치 `codex/ego-auto`의 `bf64d2d`에 `origin/main`의 `0cf0cc6`을 병합했습니다. 강타의 예비 동작·접촉·진동·후속 동작과 격파 잔해, 골렘 반격의 접촉 프레임을 가져왔습니다. 작업 브랜치의 에고 자동 배치, 엄지 띠, 수동·자동 룰렛, 표시 이름을 병합 결과에서 확인했습니다.

설정에서는 타격 진동과 룰렛 자동 진행을 각각 저장하고 복원합니다. 골렘 반격 검사는 수동 룰렛의 시작과 정지를 거쳐 피해·체력·접촉 자세를 같은 시점에서 확인합니다. 자동 에고 정확 방어와 자동 룰렛 경로도 별도로 확인합니다.

## 검증

- 빌드와 단위 테스트 185개가 통과했습니다.
- 모바일 스모크 106개가 기본 글꼴과 Ubuntu 패키지의 WenQuanYi Zen Hei 글꼴을 적용한 Windows Chromium에서 각각 통과했습니다. 해금 화면 검사는 표시 순간을 기록하도록 보강하고 기본 글꼴에서도 해당 검사 두 개를 다시 통과했습니다.
- 기본 봇과 규칙판 7 상세 출력 8개가 `bf64d2d`와 바이트 단위로 일치했습니다. 규칙판 7은 안전·강적 경로, 시드 시작값 8192·12288, 영구 해금 0·10장의 조합마다 4,096등반을 실행했습니다.
- 320×568·390×844에서 골렘 반격은 모두 접촉 프레임 4에 표시됐습니다. 체력 20인 골렘은 12가 남았고, 체력 1인 골렘은 0으로 바뀌면서 격파 잔해 10조각이 그려졌습니다.
- 320×568 브라우저에서 진동 API 호출을 기록했습니다. 강타는 24ms, 격파는 52ms를 한 번 요청했고, 진동을 끈 격파는 호출 0회였습니다.
