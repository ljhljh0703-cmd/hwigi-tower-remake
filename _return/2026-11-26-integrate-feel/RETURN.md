# 회귀탑 리메이크 · 전투 연출과 화면 통합

공개 규칙판 6의 `a10212b`에서 시작해 `integrate-feel`에 네 로컬 브랜치를 순서대로 병합했다. 각 브랜치의 끝점은 `38b61ce`, `55b6ab1`, `2bf3c9c`, `4a5d3a2`다. 첫 판 안내는 별도 작업 범위다.

| 겹친 화면 | 선택과 이유 |
| --- | --- |
| 보상 | 규칙판 6의 가로 3칸 상자와 선택 후 쉬운 설명을 채택했다. 일반 보상의 세 자리와 동전, 강적의 유물 선택, 보스의 네 카드와 장착 전용 칸을 그대로 보여 준다. 도감형 보상 행은 제외하고 키보드 화살표 이동을 가져왔다. |
| 패배 | `55b6ab1`의 독립 게임 오버와 마지막 전장 구도를 채택했다. 실제 도달 층과 생존 적을 보여 주고, 쓰러진 회귀자 아래에 재도전과 로비 버튼을 둔다. 연출 브랜치의 접촉·후속 동작은 이 화면으로 넘어가기 전에 재생한다. |
| 정확 방어 | 배치 중에는 방어 칸에 `✓ 정확`을 표시하고, 판정 뒤에는 실제 정확 방어 타점과 골렘 전신 자세를 보여 준다. 판정이 룰렛을 열면 전장을 멈추고 당첨 결과를 표시한 뒤 반격을 이어 재생한다. 반사로 공격을 돌려보내는 기믹과 황제의 방패 첫 턴은 규칙판 6 판정을 따른다. 거울과 뿔처럼 결과에 선택이 필요한 경우 선택을 유지한다. |
| 갈림길·특전 | `38b61ce`의 짧은 특전 카드와 돌문·적 도트 배치를 채택했다. 돌문 위에 규칙판 6의 강적 유물 표시를 얹었고 중간 보스의 이름과 예고를 살렸다. |
| 6층 보스 모션 | 연출 시트보다 나중에 추가된 쇠사슬 집행관은 규칙판 6의 대기·준비·공격·피격 4컷을 현재 모션 경로에 연결했다. 6층 보스의 모습과 공통 타점·후속 처리가 함께 작동한다. |

## 검증

- `npm ci`, `npm test`, `npm run build`, `npm run smoke`를 실행했다. 단위 테스트 153개와 두 크기의 헤드리스 Edge 스모크를 확인했다.
- `npm run bot`의 합쳐서 캡처한 표준 출력과 표준 오류 1,266바이트를 `fc /b`로 대조했다. 기준 `a10212b`와 SHA-256 `F3406E44431762FD4A5DFC9E419D712CEE9D450B65FED9D5243593E09A59E416`이 일치했다. 전투 엔진, 지도, 적 수치, 보상, 특전, 저장 파일의 소스도 기준과 일치한다.
- 실제 로비부터 특전, 첫 전투, 승리 보상, 새로고침, 2층 갈림길까지 조작했다. 정확 방어에서는 주사위를 하나 빼자 표시가 꺼지고 방어 칸 빈 곳을 탭해 다시 채우자 표시가 켜졌다. 골렘 전장 캔버스의 정지 시작과 당첨 순간 픽셀이 같았고, 반격 후의 체력과 턴은 엔진 결과와 같았다.
- 재현용 저장에서 기믹 예고 다섯 종, 적 상태와 제동 왕관의 자동 룰렛, 6층 보스 유물 수령 후 7층 진입, 실제 패배와 두 키보드 경로를 검사했다. 움직임 줄이기와 무음에서 정확 방어 직전 저장을 복원해 회전 연출과 소리 없이 반격이 한 번만 적용되는 것을 확인했다.
