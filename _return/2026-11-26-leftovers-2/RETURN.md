# 도감 문구 복원

`ea3e680`에서 해요체로 바꾼 도감 전용 문구 50줄을 `1678624` 원문으로 복원했다. 다음 층, 적 기믹, 공격 예고, 전투 표시, 해금, 소리, 완주 인장과 이전 규칙판의 전용 설명이 포함된다. 기준본부터 해요체였던 문장도 원문대로 표시된다.

| 설명 | 도감 | 보상·보유 상세·특전 화면 |
| --- | --- | --- |
| 보스 유물 4종 | `1678624`의 합니다체 원문 | `ea3e680`의 해요체 |
| 일반 보상·유물·특전 공용 문구 | `1678624`에도 쓰이던 해요체 | 기존 해요체 |

보스 유물은 도감 전용 설명을 두고 기존 체력·방패 상수를 사용한다. 최종 도감의 규칙판 1–6 전체 데이터를 `1678624`와 대조했다. Edge Chromium에서 두 모바일 크기로 규칙판 5·6의 실제 도감을 열어 제목·항목·설명이 기준본과 일치함을 확인했다. 6층 승리 후 보스 유물 네 장의 선택 미리보기와 회복 왕홀의 보유 상세에서 해요체를 확인했다.
