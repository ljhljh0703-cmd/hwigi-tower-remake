# 공개판 작업 통합

`codex/integrate-scattered`는 `fetch`로 확인한 `origin/main`의 `134f94d`에서 시작했다. 요청에 적힌 `a112a5c`는 규칙 비교의 기준으로 사용했다. 런타임 통합은 `5ead905`까지이며, 반환서와 사진은 그 빌드에서 검증했다.

## 반영한 작업

- `794b38d` → `300db62`. 주사위가 바닥에 닿고 튀는 그림과 소리, 재굴림 해금음, 에고 확정음과 도착음을 합쳤다. 해금 화면은 숫자 없는 조건 그림 위에 주사위 원화를 쓰도록 CSS 충돌을 해결했다. 늦게 로드된 소리, 프레임 건너뜀, 무음, 속도 변경, 화면 이탈도 스모크에서 확인했다.
- `5a75ab5` → `c8b7c10`. 주사위 원화와 그림 룰렛, 반격 시계의 단계별 검증을 합쳤다. 반격에서 하단 버튼을 눌러 회전을 시작하고 다시 눌러 멈춘 뒤 피해가 한 번 적용된다. 설정의 자동 진행, 잠든 에고의 6·8칸 표시, 자동 에고 배치, 엄지 아이템 띠와 확정 이름을 두 화면 크기에서 회귀 검사했다.
- `e27da8a`의 구현 커밋 `80c983b` 일부 → `5ead905`. 가벼운 피격의 카메라가 접촉 방향으로 움직였다가 감쇠하게 했다. 기존 효과 시트의 돌·황동 칩과 얼음 서리 컷을 재사용하고, 살아남은 적에서 `grit`·`rebound`·`frost`를 타격음 105ms 뒤에 한 번 재생한다. 강타는 접촉 정지 뒤에 같은 후속 간격을 둔다.
- 공개판의 `0cf0cc6`과 `134f94d`에는 공통 접촉 정지, 강타·격파의 복귀 반동, 재질별 픽셀, 전신 격파 파편과 타격별 체력 표시가 있었다. 가벼운 피격에만 위 변경을 적용하고, 공개판의 무거운 칼끝 타점과 격파 시점을 그대로 사용했다. 이전 브랜치의 별도 프레임 강제 표시(`openingContactUntil`, `paintOpeningFollow`)와 체력 콜백은 현재 공통 정지 및 타격별 체력 갱신과 중복돼 제외했다. `impact-material.ts`는 이미 공개판에 있는 파일을 사용했다.
