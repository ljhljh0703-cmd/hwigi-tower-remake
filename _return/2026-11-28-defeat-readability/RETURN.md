# 격파 가독성 검증 기록

## 재현과 원인

공개 기준은 `0cf0cc6`이다. 시드 12로 새 게임을 시작해 방패 특전을 선택하고 1층에서 두 턴 모두 공격한다. 첫 턴은 6·3·3으로 12 피해, 둘째 턴은 4·5·3으로 남은 11 HP를 깎는다. 기존판은 마지막 숫자를 적 몸통에 띄웠다. 원화와 벽은 회색 중간톤을 공유했고, 오른쪽으로 몰린 조각이 화면 끝에서 겹쳤다. 기존의 파편 개수 검사는 이 장면에서도 통과했다.

## 연출과 판정

| 항목 | 구현 |
| --- | --- |
| 접촉과 분리 | 기존 영웅의 준비·디딤·공격·후속 컷과 적의 피격 전신 1컷을 재사용한다. 신규 원화 0장. 영웅 발 (26,39), 칼끝 (47.5,20.5), 일반 골렘 피격 시트 `public/art/motion/golem.png`의 발 (40,29), 전용 반격 `golem-counter.png`의 발 (52,40)을 사용한다. 강타 접촉은 보통 속도 224ms, 휘두름 소리는 그 60ms 전이다. |
| 조각과 바닥 | 접촉 +84ms에 원래 불투명 픽셀을 일곱 부위로 나눈다. 원화의 어두운 이음새와 밝은 점을 남기고 새 절단면에 방향성 있는 빛과 짧은 어두운 턱을 준다. 얼음과 황동의 단면 색을 구분한다. 조각마다 거리가 다른 포물선과 정수 배율을 쓰고, 첫 착지 +348ms에 착지음 1회, +540ms에는 잔해가 정지한다. 접지 그림자는 모든 조각보다 먼저 바닥에 그린다. |
| HUD와 접근성 | 격파 중에는 피해를 대상별 체력 카드에서 읽는다. 세 카드의 순서는 나·호위·주인이다. 호위가 죽어도 살아 있는 적의 예고를 보존하고 조각이 그 아래로 지나간다. 동작 줄이기에서는 정지 잔해와 숫자가 기존 해금 대기 동안 유지된다. 타격 효과음이 꺼져도 같은 정보를 읽을 수 있다. |
| 체력 정산 | 모델이 확정한 `hitsTaken`을 사용한다. 중간 타격은 접촉한 프레임에 표시 체력만 갱신한다. 마지막 타격, 가시, 심장 부활, 승리 치유는 기존 결산 순서로 표시한다. |

## 실제 화면과 반례

두 화면 모두 Edge 모바일 에뮬레이션에서 실제 빌드를 실행했다. 비교 빌드는 `index-BhXUYUeV.js`, 체력 동기화까지 포함한 작업 빌드는 `index-RyveaR9g.js`다. 두 빌드의 SHA-256과 각 측정의 출처는 [관측값](observations.json)에 있다. [정상 속도 녹화](after/320x568-playback.webm)는 비교 빌드 영상이다.

반경 암막을 쓴 첫 후보는 벽과 바닥의 무늬가 사라져 반려했다. DPR 2 빠름의 `−11`은 이전 후보에서 320px 카드 오른쪽으로 1.66 CSS px 나갔고, 수정 후 양쪽 화면에서 6 CSS px가 남았다. 동작 줄이기의 해금 대기에서는 이전 후보의 숫자가 즉시 사라졌다. 작업 빌드에서는 +240ms에 같은 잔해와 숫자가 남고 +251ms에 해금 화면이 나타났다.

`index-BhXUYUeV.js`에서는 호위전의 첫 피해가 `22/22 −4`로 보였다. 두 화면 모두 작업 빌드에서 `18/22 −4`가 나오고 124ms 뒤 두 번째 접촉에서 `9/22 −9`가 나온다. 각 피해의 표시·체력 변경·소리 시각이 일치하고 다음 턴의 체력도 9다. 동작 줄이기에서 가시 사망은 12→7→3→0, 심장 부활은 5→1→0→9, 승리 치유는 17→12→22를 추가 대기 없이 표시했다.

## 재발 방지와 검사 범위

출고 기준과 정상 속도 육안 반려 조건을 [프로젝트 지침](../../AGENTS.md)과 [기획·검증표](../../docs/monster-design-template.md#격파-가독성-검증표)에 반영했다. 숫자를 숨겼을 때의 실제 화면 차분, 조각의 불투명 픽셀, 배경 밝기, 카드 안쪽 여백, 체력 변경 시각을 자동 검사한다. 방패와 숫자가 겹치거나 수치가 맞아도 원화와 바닥이 한 덩어리로 읽히는 장면은 반려한다.

비교 빌드에서 단위 180건과 전체 모바일 110건이 통과했다. 체력 동기화 작업 빌드에서는 단위 180건과 격파·정산 모바일 26건을 실행했다. 비교판은 첫 타격 체력 검사에서 실패하고 작업판은 통과했다. 이 작업 기록의 기준 브랜치는 `0cf0cc6`에서 갈라졌으며 공개 반영은 별도 통합 검토 대상이다.
