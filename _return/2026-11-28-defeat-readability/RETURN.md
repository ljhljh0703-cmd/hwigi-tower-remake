## 제작과 반례

- 기존 준비·디딤·접촉·후속 원화를 유지하고 피격 시트의 불투명 부분을 일곱 조각으로 나눴다. 영웅의 발 기준은 (26,39), 칼끝은 (47.5,20.5)다. 가시 골렘은 `public/art/motion/golem.png`의 발 (40,29), 전용 반격은 `golem-counter.png`의 발 (52,40)을 쓴다. 강타 기준 시각은 휘두름 164ms, 접촉 224ms다. 조각은 접촉 +84ms부터 갈라지고 첫 착지음은 +348ms에 한 번 난다.
- 첫 조명 후보는 전장에 큰 검은 원이 보여 반려했다. 최종본은 원래 이음새·표면 무늬를 살리면서 중간톤에 반사광을 주고, 새 절단면의 아래·오른쪽에만 반투명 턱을 그린다. 재질별 단면색과 바닥 접지 그림자는 원화 픽셀 배율에 맞춘다.
- DPR 2 빠름에서 `−11`이 오른쪽 카드 경계를 벗어났던 반례를 재시험했다. 두 화면에서 숫자 오른쪽에 6 CSS px가 남는다. 7층 호위전은 나·호위·주인 세 카드와 살아 있는 주인의 예고를 함께 검사한다. 예고 7을 방어해 실제 4를 맞은 순간 `18/22 −4`, 124ms 뒤 둘째 타점에 `9/22 −9`가 표시된다. 피해·표시 체력·소리는 각 접촉에서 함께 바뀌고 다음 턴 체력은 9다. [320px 첫 타격](cases/320x568-guard-2x-211ms.png) · [320px 둘째 타격](cases/320x568-guard-2x-370ms.png) · [390px 첫 타격](cases/390x844-guard-2x-211ms.png)
- 보스 이름표가 320px에서 +160·211ms에 조각 6·165픽셀을 덮었다. 보스 파편의 최대 상승 높이에 실제 이름표 하단과 여백을 반영했다. 최종본의 두 시점 모두 0픽셀이다. [보스 이름표와 파편](cases/320x568-boss-211ms.png)
- 통합 검토에서 320px DPR 2 빠름의 첫 배치 안내가 +340·560ms에 1,715·770픽셀을 가렸다. 이전 후보에서 턴 확정 클릭 직후 안내가 열린 상태임을 두 화면에서 재현했다. 최종본은 배치 중 안내를 보여 주고 실제 턴 판정이 확정된 입력에서 닫는다. 두 시점의 HUD 가림은 0픽셀이다. 빠름의 프레임 표시는 보통 속도 기준 경과량이며 실제 경과 시간은 절반이다. 출고 기준은 [프로젝트 지침](../../AGENTS.md), 재현 방법과 반려 조건은 [기획·검증표](../../docs/monster-design-template.md#격파-가독성-검증표)에 있다. 기존 공개 번들에서 기본·호위·두 규칙 해금의 모바일 반례 8건이 실패했다. 최종 빌드는 단위 검사 185건과 전체 모바일 브라우저 검사 134건을 통과했다. 격파·표시 체력·해금 전용 28건은 이 134건에 포함된다.

독립 검토자는 위의 JS·CSS 해시에서 관련 브라우저 82건과 단위 185건, 시드 12 정상 속도 녹화, 두 화면 폭에서 다섯 환경의 픽셀 검사, 호위 체력 갱신을 통과했다고 확인했다. 320px 보스의 큰 머리·견갑 조각은 이름표 아래로 지나며 비행 방향을 읽을 수 있었다. 최종 커밋 소스 대조와 배포 지시는 검토자가 별도로 진행한다.
