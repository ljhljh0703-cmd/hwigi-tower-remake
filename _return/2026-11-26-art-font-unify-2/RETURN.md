# 공개판 UI · 게이머 게이트 수정

기준판은 `744f1f4`, 작업 브랜치는 `codex/art-font-unify`다. Edge Chromium에서 두 배포용 빌드를 같은 시드와 진행 상태로 열었다. 왼쪽이 수정 전, 오른쪽이 수정 후다.

## 수정과 확인

- 일반 보상·상점 카드와 지도의 큰 표식은 24×24 PNG를 48×48 CSS px로 표시한다. 보스 보상과 시작 특전은 24×24px로 표시한다. 픽셀 아이콘에는 `image-rendering: pixelated`를 적용했다. 보상 세 칸의 버클, 붕대, 연결 고리와 더하기 표시를 실제 크기에서 확인했다. 버클은 띠와 잠금쇠로, 약초 붕대는 포개진 붕대 두 장과 가운데 패드·구멍으로 도안을 단순화했다.
- 상단의 하트·동전·소리·도감과 좁은 전투 표식에는 기존 선 아이콘을 복원했다. 동전 수는 옆 층수와 글꼴·크기·굵기·색이 같은 것을 두 크기에서 확인했다.
- 주사위를 고르면 공격·방어 칸에 밝은 점선이 생긴다. 배치하면 해당 칸에 청회색 석판과 밝은 테두리가 남는다. 공격과 방어에 각각 주사위를 넣고 뺀 뒤 빈 칸, 배치 가능, 배치 완료 표시가 실제 입력과 함께 바뀌는 것을 확인했다.

## 검증

- `npm run build` 성공. 실제 배포용 경로 `/hwigi-tower-remake/`에서 아이콘 로드와 화면 배치를 확인했다.
- `npm test` 153개, `npm run smoke` 32개 통과. 모바일 스모크의 첫 등반에 보상 그림 로드·48px 크기, 동전 수의 글자 스타일, 공격 칸의 배치 가능·완료 상태 검사를 추가했다.
- `npm run bot` 표준 출력은 수정 전 `744f1f4`와 최초 기준 `f84d495` 양쪽에 바이트 단위로 일치했다. 1,266바이트이며 SHA-256은 `f3406e44431762fd4a5dfc9e419d712cee9d450b65fed9d5243593e09a59e416`이다.
