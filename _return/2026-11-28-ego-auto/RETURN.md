# 에고 주사위 자동 배치와 해금 안내

- 규칙판 7에서 이번 턴에 같은 눈 셋을 놓으면 에고가 깨어난다. 공격과 방어에 나눠 놓을 수 있고 봉인된 눈은 제외한다. 이어지는 눈 셋은 순서에 관계없이 같은 칸에 놓으면 재굴림을 연다.
- 금색·청색 눈금과 진행 칩은 해금할 수 있는 두 눈이 있을 때 표시된다. 첫 설명 카드, 조건 창과 도감은 빈 주사위 그림으로 조건을 표시한다. 진행 칩에는 현재 배치에 필요한 눈을 따로 표시한다. 첫 2/3 알림은 등반당 한 번이고, 에고가 깨어날 때는 ‘다시, 여기.’와 함께 회귀자 옆에 내려앉는다.
- 에고는 일반 주사위 세 개와 따로 대기한다. 턴 끝에 시드로 한 번 굴려 확정 기획의 점수식으로 공격·방어·쉼을 고른다. 보통 연출 속도에서 0.4초 동안 도착 칸을 표시한 후 전투를 판정한다. 양면 심장을 장착하면 고른 홀짝에서 굴린다.
- 규칙판 7의 예전 배치 저장은 일반 주사위와 배치를 복원하고 에고를 별도로 대기시킨다. 비행 중 새로고침하면 저장된 배치로 돌아가며 턴을 다시 끝낼 때 에고의 눈이 같다. 규칙판 1~6 저장은 각 규칙판의 에고 동작으로 이어진다.

## 규칙판 7 봇 완주율

각 행은 4,096판이다. 기준은 `origin/main`의 `55df40d`다. ‘자동만’은 기존 해금 조건을 적용한 채 에고 자동 배치와 그에 맞춘 봇 정책을 적용한 비교 실행이다. ‘최종’은 공격·방어에 걸쳐 같은 눈 셋을 인정하는 최종판이다. 봇은 실제 굴림 전에 가능한 눈을 평균해 일반 주사위 배치를 선택한다.

자동 배치만 적용한 비교 실행은 기준보다 2.10~5.52%p 낮았다. 두 변경을 적용한 최종판은 모든 조합에서 기준 대비 3%p를 넘었다. 수치 조정은 총괄 판단 사항이다.

## 검증

- 빌드, 단위 테스트 185개, `npm run bot`을 통과했다. 단위 테스트는 에고가 정확 방어·처치·저체력 방어를 고르는 세 예시, 분산 배치 해금, 봉인 반례, 양면 심장, 합공과 저장 복원을 포함한다.
- 320×568·390×844 Chromium 스모크 88개가 통과했다. 해금 신호, 첫 안내 1회, 도감의 잠김·열림, 자동 배치와 저장된 에고 결과를 확인했다. 에고가 가시 골렘의 정확 방어를 완성하는 경우에는 룰렛 중 자세와 전장 크기 유지, 효과음 재생 순서, 룰렛 정지 뒤 피해 적용을 확인했다.
