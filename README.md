# 회귀탑

적의 다음 수가 한 방인지 연타인지 보고, 주사위 3개를 공격과 방어에 나누는 회색 상자 전투입니다.

- 주사위를 공격이나 방어 칸으로 끌어다 놓거나, 여러 개를 선택한 뒤 칸을 누릅니다. 선택한 주사위를 끌면 선택한 묶음을 옮깁니다.
- 턴마다 한 번, 선택한 주사위를 함께 다시 굴립니다. 새 눈은 낮아져도 그대로 씁니다.
- 한 방 피해와 방어 합이 딱 맞으면 반격 룰렛을 한 번 돌립니다. 보상은 반격 피해 1·2·3·4 또는 마타이오스와 합공 피해 6·8입니다. 방어 합이 더 높으면 피해만 막습니다.
- 주소에 `?seed=42`처럼 시드를 붙이면 같은 판을 다시 재현할 수 있습니다.

## 실행

Node.js 22.18 이상을 사용합니다.

```sh
npm ci
npm run dev
npm test
npm run bot
npm run build
```

봇 리포트는 512개의 같은 시작 시드에서 각 배치 정책을 비교합니다. 여러 배치가 남는 턴의 집계는 예상 반격 피해와 현재 턴의 체력·피해만으로 계산합니다.
